# Artwork archive (not published)

This folder is the archived image library from before the site revamp. Eleventy does **not** read or copy anything from here, so nothing in this folder appears on the live site.

- Keep the existing files as source originals.
- To use one on the site, copy it into `src/assets/images/<section>/` and reference that new path from your content. See `ASSET_GUIDE.md`.
- New images for pages belong directly in `src/assets/images/`, not here.

The nested folders (`generated/`, `projects/`, `thoughts/`, etc.) are historical groupings. They are kept only so the originals stay identifiable; do not treat them as a place to file new writing or new site assets.

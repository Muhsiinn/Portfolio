

## Overview

Jonas AI is a full-stack, AI-powered German learning platform that delivers personalized daily practice through reading, writing, roleplay, and teacher-style chat.

The app generates a lesson from each learner's daily situation, including article content, vocabulary, grammar focus, and comprehension questions. It also provides writing goals with AI evaluation, guided roleplay sessions with performance scoring, and progress tracking through stats, activity history, and leaderboard features.

## Key Highlights

- Personalized daily lessons generated with LLM workflows
- AI writing evaluation with actionable feedback and scoring
- Interactive roleplay practice with automatic session evaluation
- Teacher chat assistant with contextual language guidance
- Premium subscription flow with Stripe checkout and webhooks
- User auth with email verification and protected premium features

## Tech Stack

- Frontend: Next.js (App Router), TypeScript, Tailwind CSS
- Backend: FastAPI, SQLAlchemy, Alembic, PostgreSQL
- AI/Automation: LLM-driven workflows for lesson, writing, and roleplay generation/evaluation
- Payments: Stripe subscriptions

## Outcome

This project demonstrates end-to-end product engineering: designing learning workflows, integrating AI into user-facing features, building secure APIs, and shipping a monetized SaaS-style experience.

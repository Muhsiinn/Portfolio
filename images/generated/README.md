# Generated illustration originals

This folder keeps the full-resolution PNG outputs from the illustration work in this repository. They are source assets for future selection, cropping, or conversion; the site may use optimized copies from its section folders.

## Adding future artwork

Keep untouched generations in this folder. To make a selected image available to the website, put a web-ready copy into one of these folders:

- `home/` — homepage composition (also add `section = "home"` and a `position` such as `lower-right` in `content/illustrations.md`)
- `research/`
- `ai/`
- `neuroscience-psychiatry/`
- `other/`
- `thoughts/`
- `blog/`
- `scrapper/`
- `about/`

The build discovers supported images in these folders, adds them to `illustrations-index.json`, and copies them to `_site`. For per-image alt text, captions, credits, or page placement, add a TOML record in `content/illustrations.md`; the `file` value is relative to `images/`, for example `generated/ai/network-study.webp`. Images directly in this folder are source/archive material and are not published.
